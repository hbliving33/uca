# Union Capital Associates website

Static site, hosted on GitHub Pages.  No build step: edit the HTML and push.

- `index.html`: home page with the payment estimator
- `financing.html`, `industries.html`, `about.html`, `contact.html`: inner pages
- `thanks.html`: shown after the contact form is sent
- `404.html`: page-not-found screen
- `assets/css/site.css`: all styles
- `assets/js/site.js`: menu, estimator and form helpers
- `assets/img/mark.svg`: logo mark and browser tab icon

Photos load from Unsplash (free for commercial use under the Unsplash License).
The contact form sends to shickerson@ucacorp.net through FormSubmit.
